# VEON demo base

Техническая основа демо главной страницы (Astro 5, без лишних зависимостей): layout с `lang`, мета-тегами, skip-link и `noindex`; нейтральные сброс, фокус, контейнер, плавная прокрутка к якорям; хук анимации появления `data-reveal` (задержка — `style="--reveal-delay:120ms"`) с учётом `prefers-reduced-motion`; оболочка секции с `id` и `data-rec`; `FutureLink` — неактивный пункт для будущей страницы с подсказкой «Раздел в разработке».

**Дизайна здесь нет и быть не должно:** палитра, шрифты, композиция, компоненты и характер анимаций создаются для каждого клиента по `design/concept.md` (уровень дизайна и анимации — `veon-project/references/demo.md` §4). Плейсхолдеры `{{…}}` обязаны исчезнуть (их ловит `veon_check.py`).

**Только главная:** в `src/pages/` — один `index.astro` (служебная `404.astro` допустима). Никаких ссылок на текущий сайт клиента: разделы главной — якоря `#id`, будущие страницы — `<FutureLink note="…">`.

**Скрипты выключены — контент виден** (Floor Hallmark, `docs/process/hallmark.md`): `Base.astro` ставит класс `js` на `<html>`, скрытые до анимации состояния пишутся только под `.js`. В стилях компонентов Astro (scoped) — через `:global(.js) …`, иначе правило молча не сработает. Первая строка `src/styles/tokens.css` — штамп Hallmark, его поля заполняются из `design/concept.md`.

## Локальный запуск и сборка (macOS и Windows)
Нужен Node.js 18.20.8+ (лучше 20 или 22).
```bash
npm install          # первый раз и после клонирования репозитория
npm run dev          # разработка: адрес из вывода, обычно http://localhost:4321
npm run build        # сборка в dist/ (статические файлы)
npm run preview      # просмотр собранной версии
```

## Готовность к публикации
Сборка — обычный статический сайт в `dist/` (`index.html`, CSS, JS, изображения) без серверной части: его можно разместить на любой платформе статического хостинга без изменения кода (команда сборки `npm run build`, папка публикации `dist`). Публикацию демо по ссылке выполняет `veon_final.py publish`; домены не подключаются. Демо помечено `noindex`; при переходе к полной разработке метатег убирается.
